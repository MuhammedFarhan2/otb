# AL-AZHAR's OTB - Admin Panel

Admin pages for the AL-AZHAR's OTB school programme competition.

## Pages
- `admin home.html` - desk hub
- `marks.html` - marks overview + manual overall scores (Submit / Submit Overall)
- `lock.html` - lock/unlock programmes for judging
- `remote.html` - remote control for the audience screen
- `videos.html` - video management
- `edit-marks.html` - edit submitted marks
